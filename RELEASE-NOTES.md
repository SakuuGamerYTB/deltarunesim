## Télécharger

- macOS Apple Silicon : `macos-arm64.zip`
- macOS Intel : `macos-x64.zip`
- Windows 64 bits : `windows-x64.zip`

Extraire entièrement l’archive, puis ouvrir `Lancer.command` sur Mac ou `DeltaruneSim.exe` sous Windows. Le navigateur s’ouvre sur `http://127.0.0.1:8766/`. Garder la fenêtre du lanceur ouverte pendant la partie.

Python et les fichiers du jeu sont embarqués : aucune installation ni connexion au site d’origine n’est nécessaire. Le JavaScript lisible est utilisé par défaut. Les exécutables sont non signés et non notariés ; le système peut afficher un avertissement ou en empêcher l’ouverture.

Chaque archive est construite sur son OS et son architecture cibles puis soumise à un test de démarrage et de service HTTP. Le combat, la musique et le retour arrière ont été vérifiés dans Chrome sur Mac. Cela ne couvre pas les 365 combats ni une partie graphique complète sur Windows.

Les liens externes et les téléchargements de beatmaps restent des fonctions en ligne ; les statistiques sont un instantané. Les fichiers `.sha256` permettent de vérifier les archives.
